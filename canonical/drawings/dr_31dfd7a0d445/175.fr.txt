1) Description brève : Schéma électrique en tracé rectangulaire avec deux conducteurs horizontaux et un point de connexion à gauche et à droite ; une résistance dans le conducteur horizontal supérieur ; une dérivation vers le conducteur horizontal inférieur via un condensateur à droite ; une flèche verticale vers le bas (« U_E ») entre les deux points de connexion à gauche, une flèche verticale vers le bas (« U_A ») entre les deux points de connexion à droite.

2) Description détaillée : L’image montre un schéma électrique en tracé rectangulaire avec deux conducteurs horizontaux et un point de connexion à gauche et à droite. Une résistance est insérée dans le conducteur horizontal supérieur. À droite, une dérivation vers le conducteur horizontal inférieur via un condensateur est présente. Entre les deux points de connexion à gauche, une flèche verticale vers le bas (« U_E ») est dessinée ; entre les deux points de connexion à droite, une flèche verticale vers le bas (« U_A ») est dessinée.
