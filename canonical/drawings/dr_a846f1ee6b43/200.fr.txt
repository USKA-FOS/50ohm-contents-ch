1) Description concise : Schéma de circuit avec deux conducteurs horizontaux parallèles ; les deux avec des points de connexion aux deux extrémités ; le conducteur horizontal inférieur est à la masse ; dans le conducteur horizontal supérieur, le composant « IC1 » avec connexion au conducteur horizontal inférieur ; à gauche et à droite de celui-ci, une connexion verticale entre les deux conducteurs horizontaux avec chacun un condensateur ; entre les points de connexion à gauche, une flèche verticale vers le bas (« U_E »), à droite, une flèche verticale vers le bas (« U_A »).

2) Description détaillée : Le schéma de circuit se compose de deux conducteurs horizontaux parallèles. Les deux ont un point de connexion aux deux extrémités. Le conducteur inférieur est à la masse. Dans le conducteur horizontal supérieur, il y a au milieu un composant « IC1 » avec connexion au conducteur horizontal inférieur. À gauche et à droite de celui-ci, une connexion verticale entre les deux conducteurs horizontaux est dessinée. Dans la connexion de gauche, un condensateur polarisé (deux lignes parallèles, la ligne supérieure marquée « + ») est dessiné. La connexion de droite passe par un autre condensateur. Entre les deux points de connexion à gauche, une flèche verticale vers le bas (« U_E ») est dessinée, entre les deux points de connexion à droite, une flèche verticale vers le bas (« U_A ») est dessinée.
