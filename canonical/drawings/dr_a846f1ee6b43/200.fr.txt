1) Description courte : Schéma électrique avec deux conducteurs horizontaux parallèles ; les deux avec des points de connexion aux deux extrémités ; conducteur horizontal inférieur relié à la masse ; dans le conducteur horizontal supérieur, module « IC1 » avec connexion au conducteur horizontal inférieur ; à gauche et à droite de celui-ci, une connexion verticale entre les deux conducteurs horizontaux avec respectivement un condensateur ; entre les points de connexion de gauche, une flèche verticale pointant vers le bas (« U_E »), entre les points de connexion de droite, une flèche verticale pointant vers le bas (« U_A »).

2) Description détaillée : Le schéma électrique consiste en deux conducteurs horizontaux parallèles. Les deux ont un point de connexion à chaque extrémité. Le conducteur inférieur est relié à la masse. Dans le conducteur horizontal supérieur se trouve au centre un module « IC1 » avec connexion au conducteur horizontal inférieur. À gauche et à droite de celui-ci, une connexion verticale entre les deux conducteurs horizontaux est représentée. Dans la connexion de gauche est inséré un condensateur polarisé (deux lignes parallèles, la ligne supérieure étiquetée « + »). La connexion de droite passe par un autre condensateur. Entre les deux points de connexion de gauche est représentée une flèche verticale pointant vers le bas (« U_E »), entre les deux points de connexion de droite est représentée une flèche verticale pointant vers le bas (« U_A »).
