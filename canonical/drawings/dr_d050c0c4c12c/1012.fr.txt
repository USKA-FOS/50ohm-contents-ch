Description détaillée : À gauche, une ligne conductrice horizontale traverse un symbole de composant rectangulaire ; dans le rectangle se trouve une diagonale allant de bas gauche à haut droit. Sous le rectangle est écrit « ϑ » avec plusieurs petites flèches vers le haut, suivi de l'étiquette « PTC ». À droite, le même symbole de composant rectangulaire est représenté dans une ligne conductrice horizontale, également avec une diagonale allant de bas gauche à haut droit. Sous ce rectangle est écrit « ϑ » avec une flèche vers le bas, suivi de l'étiquette « NTC ». Les deux symboles sont séparés par un espace libre.
