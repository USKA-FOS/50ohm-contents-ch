1) Description courte : Schéma de circuit en conduite rectangulaire avec deux conducteurs horizontaux parallèles et deux points de connexion à gauche (étiquetés « ZF ») ; condensateur entre les deux conducteurs horizontaux ; transformateur ; à son enroulement secondaire, un autre condensateur entre les conducteurs horizontaux ; diode dans le conducteur supérieur ; un autre condensateur entre les conducteurs horizontaux ; en parallèle, une résistance ; vers le haut, un autre condensateur vers le 3ème point de connexion droit (« NF ») ; dans le conducteur supérieur, une résistance ; ensuite, un condensateur entre les conducteurs horizontaux ; deux points de connexion vers la droite.

2) Description détaillée : L'illustration se compose d'un schéma de circuit en conduite rectangulaire avec deux conducteurs horizontaux parallèles et deux points de connexion à gauche (étiquetés « ZF »). Entre les deux conducteurs horizontaux, un condensateur est d'abord connecté, qui est en parallèle avec l'enroulement primaire d'un transformateur. À son enroulement secondaire, un autre condensateur est dessiné entre les conducteurs horizontaux. Dans le conducteur supérieur, il y a ensuite une diode. Derrière celle-ci, un autre condensateur relie les deux conducteurs horizontaux. En parallèle, une résistance est présente. De son extrémité supérieure, un autre condensateur va vers le haut jusqu'à un point de connexion à droite (« NF »). Dans le conducteur supérieur, une autre résistance suit, puis un condensateur entre les conducteurs horizontaux (la ligne supérieure marquée par « + »). Les deux conducteurs horizontaux ont chacun un point de connexion à droite.
