1) Description brève : Schéma électrique en tracé rectangulaire avec deux conducteurs horizontaux parallèles et deux points de connexion à gauche (étiquetés « FI ») ; condensateur entre les deux conducteurs horizontaux ; transformateur ; sur son enroulement secondaire, un autre condensateur entre les conducteurs horizontaux ; diode dans le conducteur supérieur ; un autre condensateur entre les conducteurs horizontaux ; en parallèle, une résistance ; plus haut, un autre condensateur menant à un troisième point de connexion à droite (« BF ») ; dans le conducteur supérieur, une résistance ; ensuite, un condensateur entre les conducteurs horizontaux ; deux points de connexion à droite.

2) Description détaillée : L'illustration consiste en un schéma électrique en tracé rectangulaire avec deux conducteurs horizontaux parallèles et deux points de connexion à gauche (étiquetés « FI »). Entre les deux conducteurs horizontaux est d'abord monté un condensateur en parallèle avec l'enroulement primaire d'un transformateur. Sur son enroulement secondaire est représenté un autre condensateur entre les conducteurs horizontaux. Dans le conducteur supérieur se trouve ensuite une diode. Derrière celle-ci, un autre condensateur relie les deux conducteurs horizontaux. En parallèle est montée une résistance. Depuis son extrémité supérieure, un autre condensateur monte vers un point de connexion à droite (« BF »). Dans le conducteur supérieur suit une autre résistance, puis entre les conducteurs horizontaux un condensateur (le conducteur supérieur étant marqué d'un « + »). Les deux conducteurs horizontaux possèdent chacun un point de connexion à droite.
