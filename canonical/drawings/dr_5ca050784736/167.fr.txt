1) Description courte : Schéma électrique avec deux conducteurs horizontaux parallèles ; le conducteur supérieur contient deux symboles de bobine ; au centre, entre les bobines, une ligne verticale avec un symbole de condensateur se sépare et rejoint le conducteur horizontal inférieur. Les deux conducteurs horizontaux ont des points de connexion à leurs extrémités.

2) Description détaillée : Le schéma électrique est composé de deux conducteurs horizontaux parallèles. Le conducteur supérieur contient deux symboles de bobine, chacun représenté par quatre demi-cercles orientés vers le haut. Au centre, entre les bobines, une ligne verticale avec un symbole de condensateur (deux traits horizontaux) se sépare et rejoint le conducteur horizontal inférieur. Les deux conducteurs horizontaux ont des points de connexion à leurs extrémités.
