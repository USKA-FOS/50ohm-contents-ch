1) Description brève : Schéma électrique en forme rectangulaire avec deux conducteurs horizontaux dotés de deux points de connexion à gauche (« BF/bande de base ») et de deux points de connexion à droite (« vers l'oscillateur ») ; dans le conducteur supérieur, une bobine et deux condensateurs montés en série ; entre eux, une dérivation vers le haut via une résistance vers le point de connexion « + » ; en outre, une dérivation vers le bas via une diode vers le conducteur horizontal inférieur ; à droite du deuxième condensateur dans le conducteur supérieur, une dérivation vers le bas via un condensateur réglable vers le conducteur horizontal inférieur ; une bobine est montée en parallèle avec ce dernier.

2) Description détaillée : L'illustration représente un schéma électrique en forme rectangulaire avec deux conducteurs horizontaux dotés de deux points de connexion à gauche (« BF/bande de base ») et de deux points de connexion à droite (« vers l'oscillateur »). Dans le conducteur supérieur se trouve une bobine, indiquée par une ligne en pointillés au-dessus, suivie de deux condensateurs montés en série. Entre les condensateurs, une dérivation monte via une résistance vers le point de connexion « + ». Une autre dérivation descend via une diode (triangle pointant vers le haut avec une ligne transversale à la pointe du triangle) vers le conducteur horizontal inférieur. À côté de la diode figure un petit symbole de circuit pour un condensateur. À droite du deuxième condensateur dans le conducteur supérieur, une dérivation descend via un condensateur réglable (symbole de circuit avec deux lignes horizontales traversées par une ligne diagonale, se terminant par un trait transversal). Une bobine (symbole de circuit avec des demi-cercles orientés vers la droite) est montée en parallèle avec ce condensateur.
