1) Description courte : <i>Schéma électrique</i> en tracé rectangulaire avec deux conducteurs horizontaux et un point de connexion à gauche et à droite ; dans le conducteur horizontal supérieur se trouve un <i>condensateur</i> ; à droite, une dérivation via une <i>résistance</i> vers le conducteur horizontal inférieur ; entre les deux points de connexion à gauche, une flèche verticale vers le bas (« U_E »), entre les deux points de connexion à droite, une flèche verticale vers le bas (« U_A »).

2) Description détaillée : L'illustration montre un <i>schéma électrique</i> en tracé rectangulaire avec deux conducteurs horizontaux et un point de connexion à gauche et à droite. Dans le conducteur horizontal supérieur est inséré un <i>condensateur</i>. À droite, une dérivation via une <i>résistance</i> mène au conducteur horizontal inférieur. Entre les deux points de connexion à gauche est dessinée une flèche verticale vers le bas (« U_E »), entre les deux points de connexion à droite est dessinée une flèche verticale vers le bas (« U_A »).
