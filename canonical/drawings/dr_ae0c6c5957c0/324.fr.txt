1) Description courte : Schéma électrique en forme rectangulaire ; sur le conducteur horizontal supérieur, à gauche un point de connexion, puis à droite un symbole de résistance, suivi d’un conducteur vertical avec le symbole d’une diode électroluminescente ; en dessous, le conducteur horizontal inférieur avec un point de connexion à gauche.

2) Description détaillée : Le schéma électrique contient un circuit rectangulaire composé de conducteurs droits. Sur le conducteur horizontal supérieur, un point de connexion est dessiné à gauche. À droite se trouve un symbole composé d’un rectangle (résistance). Il est suivi d’un conducteur vertical au centre duquel est dessiné un symbole en forme de triangle pointé vers le bas, avec une ligne horizontale en dessous et deux flèches inclinées vers le bas à droite. Il est suivi d’un conducteur horizontal inférieur avec un point de connexion à son extrémité gauche.
