1) Description courte : Schéma avec deux conducteurs horizontaux parallèles ; les deux avec des points de connexion aux deux extrémités ; dans le supérieur, une flèche vers la droite avec la mention "I" ; entre les deux conducteurs horizontaux, un conducteur vertical avec deux résistances "R_1" et "R_2" en série ; à gauche des résistances, une flèche vers le bas et la mention "U" ; à droite de "R_2", une flèche vers le bas et la mention "U_2" ; entre les deux résistances, une dérivation vers la droite avec un autre point de connexion.

2) Description détaillée : Le schéma est composé de deux conducteurs horizontaux parallèles. Les deux ont un point de connexion sans mention aux deux extrémités. Dans le conducteur horizontal supérieur, une petite flèche vers la droite avec la mention "I" est dessinée. Les deux conducteurs horizontaux sont reliés entre eux par un conducteur vertical avec deux résistances "R_1" et "R_2" en série. À gauche des résistances, une flèche vers le bas avec la mention "U" est dessinée. À droite de "R_2", une flèche vers le bas est dessinée et mentionnée "U_2". Entre les deux résistances, une dérivation avec point de connexion part vers la droite.
