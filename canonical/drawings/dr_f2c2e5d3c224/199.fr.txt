1) Description courte : Schéma de circuit avec deux conducteurs horizontaux parallèles ; les deux avec des points de connexion à l'extrémité gauche ; entre les deux points de connexion une flèche verticale "U_B" ; dans le conducteur horizontal supérieur une flèche vers la droite "I_1" ; entre les deux conducteurs horizontaux un conducteur vertical avec deux résistances "R_1" et "R_2" en série et une flèche vers le bas "I_2" ; à gauche des résistances respectivement une flèche vers le bas "U_1" ou "U_2" ; entre les deux résistances une dérivation vers la droite, puis une courbure vers le bas avec une autre résistance "R_L" parallèle à "R_2" ; dans la suite du conducteur vertical une flèche vers le bas "I_L" et connexion au conducteur horizontal inférieur.

2) Description détaillée : Le schéma de circuit se compose de deux conducteurs horizontaux parallèles. Les deux ont un point de connexion à l'extrémité gauche. Entre les points de connexion est dessinée une flèche verticale étiquetée "U_B". Dans le conducteur horizontal supérieur se trouve une flèche vers la droite avec l'étiquette "I_1". Entre les deux conducteurs horizontaux passe un conducteur vertical avec deux résistances en série, étiquetées "R_1" et "R_2", et une flèche vers le bas avec l'étiquette "I_2". À gauche des résistances se trouve respectivement une flèche vers le bas avec l'étiquette "U_1" ou "U_2". Entre les deux résistances, une dérivation part vers la droite, puis vers le bas. Ici, une autre résistance "R_L" est dessinée en parallèle avec "R_2". Dans la suite du conducteur vertical, il y a une flèche vers le bas avec l'étiquette "I_L" ainsi qu'une connexion au conducteur horizontal inférieur.
