1) Description courte : partie supérieure : diagramme avec un axe horizontal « t » et un axe vertical « U » ; courbe sinusoïdale avec une amplitude croissante et décroissante ; partie inférieure : schéma de circuit en conduite rectangulaire avec deux conducteurs horizontaux parallèles et deux points de connexion à gauche (marqués « ZF ») ; condensateur entre les deux conducteurs horizontaux ; transformateur ; un autre condensateur entre les conducteurs horizontaux à son enroulement secondaire ; diode dans le conducteur supérieur ; un autre condensateur (marqué « X ») entre les conducteurs horizontaux ; en parallèle, une résistance ; vers le haut, un autre condensateur vers le 3ème point de connexion à droite ; dans le conducteur supérieur, une résistance ; ensuite, un condensateur entre les conducteurs horizontaux ; deux points de connexion vers la droite.

2) Description détaillée : L'image se compose de deux parties. En haut, un diagramme avec un axe horizontal « t » et un axe vertical « U » et une courbe sinusoïdale avec une amplitude croissante et décroissante est représenté. En bas, il y a un schéma de circuit en conduite rectangulaire avec deux conducteurs horizontaux parallèles et deux points de connexion à gauche (marqués « ZF »). Entre les deux conducteurs horizontaux, un condensateur est d'abord connecté, qui est en parallèle avec l'enroulement primaire d'un transformateur. Un autre condensateur est dessiné entre les conducteurs horizontaux à son enroulement secondaire. Dans le conducteur supérieur, il y a ensuite une diode. Derrière celle-ci, un autre condensateur (marqué « X ») relie les deux conducteurs horizontaux. En parallèle, une résistance est connectée. De son extrémité supérieure, un autre condensateur va vers le haut jusqu'à un point de connexion à droite. Dans le conducteur supérieur, une autre résistance suit, puis un condensateur entre les conducteurs horizontaux (la ligne supérieure marquée « + »). Les deux conducteurs horizontaux ont chacun un point de connexion à droite.
