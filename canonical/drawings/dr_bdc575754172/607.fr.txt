1) Description courte : partie supérieure : diagramme avec un axe horizontal « t » et un axe vertical « U » ; courbe sinusoïdale à amplitude croissante et décroissante ; partie inférieure : schéma électrique en tracé rectangulaire avec deux conducteurs horizontaux parallèles et deux points de connexion à gauche (étiquetés « FI ») ; condensateur entre les deux conducteurs horizontaux ; transformateur ; sur son enroulement secondaire, un autre condensateur entre les conducteurs horizontaux ; diode dans le conducteur supérieur ; un autre condensateur (étiqueté « X ») entre les conducteurs horizontaux ; résistance en parallèle ; au-dessus, un autre condensateur menant au 3ᵉ point de connexion droit ; dans le conducteur supérieur, une résistance ; ensuite, un condensateur entre les conducteurs horizontaux ; deux points de connexion à droite.

2) Description détaillée : L'illustration se compose de deux parties. En haut, un diagramme avec un axe horizontal « t » et un axe vertical « U » présente une courbe sinusoïdale à amplitude croissante et décroissante. En bas, un schéma électrique en tracé rectangulaire montre deux conducteurs horizontaux parallèles et deux points de connexion à gauche (étiquetés « FI »). Entre les deux conducteurs horizontaux est d'abord connecté un condensateur, placé en parallèle avec l'enroulement primaire d'un transformateur. Sur son enroulement secondaire est représenté un autre condensateur entre les conducteurs horizontaux. Dans le conducteur supérieur se trouve ensuite une diode. Derrière celle-ci, un autre condensateur (étiqueté « X ») relie les deux conducteurs horizontaux. En parallèle est placée une résistance. Depuis son extrémité supérieure, un autre condensateur monte vers un point de connexion droit. Dans le conducteur supérieur suit une autre résistance, puis entre les conducteurs horizontaux un condensateur (la ligne supérieure marquée d'un « + »). Les deux conducteurs horizontaux ont chacun un point de connexion à droite.
