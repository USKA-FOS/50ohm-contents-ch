Condensateur entre les deux conducteurs horizontaux ; transformateur ; sur son enroulement secondaire, un autre condensateur entre les conducteurs horizontaux ; diode dans le conducteur supérieur ; un autre condensateur entre les conducteurs horizontaux ; en parallèle, une résistance ; au-dessus, un autre condensateur menant au 3ᵉ point de connexion à droite ; dans le conducteur supérieur, une résistance ; ensuite, un condensateur entre les conducteurs horizontaux ; deux points de connexion à droite, celui du conducteur horizontal supérieur étant marqué d'un « X ».

2) Description détaillée : L'illustration montre un schéma électrique avec une structure rectangulaire de conducteurs, deux conducteurs horizontaux parallèles et deux points de connexion à gauche (étiquetés « FI »). Entre les deux conducteurs horizontaux, un condensateur est d'abord connecté, en parallèle avec l'enroulement primaire d'un transformateur. Sur son enroulement secondaire, un autre condensateur est représenté entre les conducteurs horizontaux. Dans le conducteur supérieur, il y a ensuite une diode. Derrière celle-ci, un autre condensateur relie les deux conducteurs horizontaux. En parallèle se trouve une résistance. Depuis son extrémité supérieure, un autre condensateur monte vers un point de connexion à droite. Dans le conducteur supérieur suit une autre résistance, puis un condensateur entre les conducteurs horizontaux (la ligne supérieure étant marquée d'un « + »). Les deux conducteurs horizontaux ont chacun un point de connexion à droite, celui du conducteur supérieur étant marqué d'un « X ».
