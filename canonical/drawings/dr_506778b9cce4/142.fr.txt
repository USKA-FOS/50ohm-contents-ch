1) Description courte : Schéma en forme de rectangle avec deux conducteurs horizontaux parallèles et deux points de connexion à gauche (marqués « ZF ») ; condensateur entre les deux conducteurs horizontaux ; transformateur ; à son enroulement secondaire, un autre condensateur entre les conducteurs horizontaux ; diode dans le conducteur supérieur ; autre condensateur entre les conducteurs horizontaux ; en parallèle, une résistance ; vers le haut, un autre condensateur vers le 3ème point de connexion à droite ; dans le conducteur supérieur, une résistance ; ensuite, un condensateur entre les conducteurs horizontaux ; deux points de connexion vers la droite, celui du conducteur horizontal supérieur marqué « X ».

2) Description détaillée : L'image montre un schéma en forme de rectangle avec deux conducteurs horizontaux parallèles et deux points de connexion à gauche (marqués « ZF »). Entre les deux conducteurs horizontaux, un condensateur est d'abord connecté, en parallèle avec l'enroulement primaire d'un transformateur. À son enroulement secondaire, un autre condensateur est dessiné entre les conducteurs horizontaux. Dans le conducteur supérieur, il y a ensuite une diode. Derrière celle-ci, un autre condensateur relie les deux conducteurs horizontaux. En parallèle, une résistance est présente. De son extrémité supérieure, un autre condensateur va vers le haut jusqu'à un point de connexion à droite. Dans le conducteur supérieur, une autre résistance suit, puis un condensateur entre les conducteurs horizontaux (la ligne supérieure marquée « + »). Les deux conducteurs horizontaux ont chacun un point de connexion à droite, celui du conducteur supérieur est marqué « X ».
