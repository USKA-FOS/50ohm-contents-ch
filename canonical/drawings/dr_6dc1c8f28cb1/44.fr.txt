1) Description brève : Schéma bloc avec deux conducteurs horizontaux et un flux de signal de gauche à droite : source de signal, amplificateur « 0,3 – 3,4 kHz » dans le conducteur horizontal supérieur, deux dérivations verticales vers le conducteur horizontal inférieur avec deux diodes parallèles dessinées en sens opposés, en parallèle une résistance variable, connexion depuis le curseur vers un filtre (« 3 kHz ») ; à droite deux points de connexion « vers l’oscillateur ».

2) Description détaillée : Est représenté un schéma bloc composé de plusieurs modules reliés par deux conducteurs horizontaux. Tout à gauche se trouve un cercle sans légende avec une ligne verticale à gauche (source de signal). Dans le conducteur horizontal supérieur suit un bloc avec un triangle pointant vers la droite (amplificateur), légendé « 0,3 – 3,4 kHz ». Derrière, deux dérivations verticales vers le conducteur horizontal inférieur avec deux diodes parallèles dessinées en sens opposés. En parallèle, une résistance variable est représentée, dont le curseur est relié à un filtre légendé « 3 kHz ». Les deux conducteurs horizontaux ont à droite chacun un point de connexion menant « vers l’oscillateur ».
