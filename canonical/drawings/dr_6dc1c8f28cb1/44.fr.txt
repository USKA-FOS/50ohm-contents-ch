1) Description concise : Schéma bloc avec deux conducteurs horizontaux et flux de signal de gauche à droite : source de signal, amplificateur « 0,3 – 3,4 kHz » dans le conducteur horizontal supérieur, deux dérivations verticales vers le conducteur horizontal inférieur avec deux diodes parallèles, dessinées en sens opposé, en parallèle un potentiomètre, connexion du contact glissant à un filtre (« 3 kHz ») ; à droite deux points de connexion « vers l'oscillateur ».

2) Description détaillée : Un schéma bloc composé de plusieurs modules connectés par deux conducteurs horizontaux est montré. Tout à gauche se trouve un cercle non étiqueté avec une ligne verticale sur le côté gauche (source de signal). Dans le conducteur horizontal supérieur suit un bloc avec un triangle pointant vers la droite (amplificateur), qui est étiqueté « 0,3 – 3,4 kHz ». Derrière celui-ci suivent deux dérivations verticales vers le conducteur horizontal inférieur avec deux diodes parallèles, dessinées en sens opposé. En parallèle, un potentiomètre est dessiné, dont le contact glissant est connecté à un filtre, étiqueté « 3 kHz ». Les deux conducteurs horizontaux ont chacun un point de connexion à droite, qui mène « vers l'oscillateur ».
