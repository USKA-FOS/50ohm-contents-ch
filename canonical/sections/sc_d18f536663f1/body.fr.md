Les systèmes de transmission numériques ne transmettent pas de signaux analogiques, mais des informations numériques. Celles-ci sont transmises sous forme de nombres binaires, appelés *bits*. Deux notions doivent être distinguées :

- *Débit de transmission de données* : il indique combien de bits sont transmis par seconde. L’unité du débit de transmission de données est le *$\unit{\bit\per\second}$*.
- *Bande passante* : nous avons déjà rencontré ce terme. Elle s’exprime en *hertz ($\unit{\hertz}$)*, comme la fréquence, et ne doit pas être confondue avec le débit de transmission de données, même si dans le langage courant on parle de débit de transmission de données comme de bande passante (par exemple pour une connexion DSL).
