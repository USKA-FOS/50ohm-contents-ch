Pour le fonctionnement radio, il est important de savoir quelles bandes de fréquences peuvent être utilisées par les radioamateurs. Cela peut être lu dans l'[annexe 1 de l'AFuV](https://50ohm.de/a1). Les questions suivantes devraient donc être faciles à répondre. L'annexe 1 de l'AFuV est disponible comme aide pendant l'examen.

<tip>
Pour ces questions, il n'est vraiment pas nécessaire d'apprendre par cœur ou de calculer : il suffit de vérifier lequel des valeurs indiquées dans la question d'examen apparaît dans la liste de l'annexe 1. Cette valeur est alors la bonne réponse. Les valeurs peuvent également se composer de plusieurs entrées, comme par exemple dans le cas de la bande des $\qty{160}{\meter}$.
</tip>
