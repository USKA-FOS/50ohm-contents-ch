Les systèmes de transmission numériques utilisent des procédés très différents pour optimiser la quantité de données (bits) transmissibles par seconde et/ou la robustesse face aux perturbations de différentes natures. Trois termes jouent un rôle important :

- *Débit de symboles* : Dans les procédés de modulation numérique, on parle également d'alphabets de modulation qui peuvent contenir un certain nombre de symboles. Dans les procédés simples, comme le radiotélétype classique, un seul bit (\num{0} ou \num{1}) est transmis par symbole, tandis que dans d'autres, il peut y avoir plus de symboles. Le débit de symboles est exprimé en *Baud (\unit{\baud})*, ce qui est l'inverse de la durée temporelle du symbole. Si, par exemple, un symbole dure \qty{20}{\milli\second}, le débit de symboles est $(\qty{20}{\milli\second})^{-1}= \qty{50}{\baud}$. La bande passante est essentiellement influencée par le débit de symboles.
- *Débit de transmission de données* : Plusieurs bits peuvent être transmis par symbole. Par exemple, la modulation de phase quaternaire a quatre états de phase différents (\qty{0}{\degree}, \qty{90}{\degree}, \qty{180}{\degree}, \qty{270}{\degree}), que nous pouvons associer aux combinaisons de bits (0,0), (1,0), (0,1), (1,1). Ainsi, deux bits peuvent être transmis par symbole, le débit de transmission de données est donc deux fois plus élevé que le débit de symboles. Il existe des alphabets de modulation beaucoup plus complexes qui peuvent transmettre beaucoup plus de bits par symbole - au détriment de la résistance aux perturbations. Le débit de transmission de données est exprimé en *$\unit{\bit\per\second}$*.
- *Bande passante* : Nous avons déjà rencontré le terme de bande passante. Elle est exprimée en *Hertz (\unit{\hertz})*, comme la fréquence, et ne doit pas être confondue avec le débit de transmission de données, même si, dans le langage courant, le débit de transmission de données est appelé bande passante (par exemple, dans le cas d'une connexion DSL).
