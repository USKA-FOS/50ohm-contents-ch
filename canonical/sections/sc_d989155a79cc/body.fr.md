Les groupes Q sont composés de trois lettres et commencent par *Q*. Ils ont été développés pour la télégraphie rapide, mais sont également utilisés en radioamateurisme dans la radiotéléphonie. Avec un point d'interrogation, de nombreux groupes forment une question, sans point d'interrogation, une affirmation ou une demande.

<margin>
| l: Groupe | X: Signification |
| QRM | Je suis perturbé par d'autres stations |
| QRN | Je suis affecté par des perturbations atmosphériques |
| QRO? | Dois-je augmenter la puissance d'émission ? |
| QRT | Arrêtez la transmission |
| QRV | Je suis prêt |
| QRX? | Quand me rappellerez-vous ? |
| QRZ? | Par qui suis-je appelé ? |
| QSB? | L'intensité de mes signaux varie-t-elle ? |
| QSL? | Pouvez-vous me confirmer la réception ? |
| QSO? | Pouvez-vous communiquer avec une station spécifique ? |
| QTH | Ma position est ... |

Pour les écouteurs (SWL), *QSL* est particulièrement important : c'est de là que vient le terme carte QSL. *QRM*, *QRN* et *QSB* décrivent différentes causes de réception difficile.

<tip>
Astuce mnémotechnique : QRM est une perturbation *m*an-made (d'origine humaine), QRN une perturbation *n*aturelle et QSB va avec la *s*trength (force) du signal qui *b*aisse et *b*ouge.
</tip>
