On dispose d’une adaptation d’impédance de 50 Ω à 2500 Ω.

Déterminons d’abord le rapport d’impédance nécessaire (du point de vue de l’antenne) :

Z_P / Z_S = 2500 / 50 = 50

Le transformateur doit donc réaliser un rapport d’impédance d’environ 1:50.

Pour les transformateurs, on sait que :
Le rapport d’impédance est le carré du rapport des spires :

(N_2 / N_1)^2 = 50

Il en découle pour le rapport des spires :

N_2 / N_1 = √50 ≈ 7

On cherche donc approximativement un rapport de spires de :

1:7
