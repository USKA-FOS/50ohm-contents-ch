Pour $\qty{3,6}{\mega\hertz}$, la longueur d’onde est d’environ

$\lambda=\frac{\qty{300000}{\kilo\meter\per\second}}{\qty{3,6}{\mega\hertz}} \approx\qty{83,3}{\meter}$.

Un dipôle demi-onde devrait donc, idéalement, mesurer environ

$\frac{\lambda}{2}\approx\qty{41,7}{\meter}$

de long. Cependant, le dipôle décrit dans la question suivante ne mesure que deux fois $\qty{15}{\meter}$, soit une longueur totale de $\qty{30}{\meter}$. Il est donc mécaniquement trop court pour $\qty{3,6}{\mega\hertz}$.

Pour le faire entrer en résonance à cette fréquence, les deux moitiés du dipôle doivent donc être prolongées électriquement. Pour cela, une bobine est insérée dans chaque branche.
