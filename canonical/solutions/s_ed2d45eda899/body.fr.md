Un transformateur avec un rapport de spires de $1:4$ ainsi qu'une résistance $R = \qty{16}{\kilo\ohm}$ sur le côté secondaire sont donnés.

Tout d'abord, nous déterminons le rapport d'impédance. Pour les transformateurs, on a:

$\left(\frac{N_S}{N_P}\right)^2 = \left(4\right)^2 = 16$

Cela signifie que l'impédance sur le côté secondaire semble être 16 fois plus grande que sur le côté primaire.

Nous cherchons l'impédance transformée sur le côté primaire:

$Z_\text{P} = \frac{Z_\text{S}}{16} = \frac{\qty{16}{\kilo\ohm}}{16}$

$Z_\text{P} = \qty{1}{\kilo\ohm}$
