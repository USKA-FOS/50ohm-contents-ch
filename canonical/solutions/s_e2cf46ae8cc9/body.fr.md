# Données
* Bande de fréquences : $\qty{100}{\mega\hertz}$
* Précision : $\qty{\pm 1}{\ppm}$

# Solution
$\unit{ppm}$ signifie *parts per million*, $\qty{1}{\ppm}$ signifie $1$ pour $10^6$.  

$\Delta f = \qty{100}{\mega\hertz} \cdot \frac{1}{10^6} = 100\cdot \cancel{10^6}\unit{\hertz}\cdot\frac{1}{\cancel{10^6}} = \qty{100}{\hertz}$
