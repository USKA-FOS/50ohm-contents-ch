## Calcul de la puissance

Nous connaissons déjà

$P = U\cdot I = \dfrac{U^2}{R} = I^2\cdot R$

<left>
Résolu pour U :
$U = \dfrac{P}{I} = \sqrt{P \cdot R}$
</left>
<right>
Résolu pour I :
$I = \dfrac{P}{U} = \sqrt{\dfrac{P}{R}}$
</right>

<note>
* Toutes les formules sont disponibles dans le recueil de formules
</note>
