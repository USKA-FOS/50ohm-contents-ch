## Abbreviazioni operative

| l: Abbreviazione | X: Significato |
| CQ | chiamata generale |
| CW | Continuous Wave; telegrafia Morse |
| DX | grande distanza o stazione lontana |
| RX | ricevitore |
| TX | trasmettitore |
| TRX | trasmettitore-ricevitore |

<note>
Le abbreviazioni internazionalmente comprensibili risparmiano tempo e facilitano la comunicazione oltre i confini linguistici. Un SWL opera in modalità ricezione (RX).
</note>

---

### Una chiamata generale

*CQ CQ CQ de DL1ABC*

* *CQ* è rivolta a tutte le stazioni in ascolto
* *de* significa *da*
* segue il nominativo della stazione chiamante
* per gli SWL è una buona opportunità per acquisire con sicurezza il primo nominativo
