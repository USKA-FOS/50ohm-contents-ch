## Réception

* La fréquence est réglée sur l'appareil radio via un bouton rotatif ou des touches
* Seules les stations sur la fréquence réglée peuvent être entendues
* Tourner lentement "sur la bande" pour entendre d'autres stations

## Différence entre oscillogramme et spectre d'amplitude

* Le spectre d'amplitude montre horizontalement les amplitudes pour différentes fréquences
* L'oscillogramme montre horizontalement les amplitudes à différents moments
