### TDMA
<left>
* Time Division Multiple Access – multiplexage temporel
* Les données numériques utiles sont séparées et envoyées successivement sur la même fréquence
* À la réception, le flux de données est reconstitué
</left>
<right>

</right>

### CDMA
<left>
* Code Division Multiple Access – procédé de multiplexage par code
* Les données numériques utiles sont codées (mélangées) avec un code numérique
* À la réception, le même code numérique est utilisé pour décoder
</left>
<right>
[picture:846:e_vielfachzugriff_cdma:Procédé de multiplexage par code avec trois signaux]
</right>
<note>
* Plusieurs signaux peuvent être transmis sur la même fréquence
</note>

### FDMA
<left>
* Frequency Division Multiple Access – procédé de multiplexage en fréquence
* Le signal numérique est réparti sur plusieurs fréquences
* Cela permet d’utiliser une bande passante plus large
</left>
<right>
[picture:845:e_vielfachzugriff_cdma:Procédé de multiplexage en fréquence avec trois signaux]
