* Malgré une faible puissance, un gain d'antenne élevé peut exister

## Distance de sécurité

* Procédure d'évaluation selon la BEMFV (règlement sur la procédure de démonstration pour la limitation des champs électromagnétiques)
* Le calcul en champ lointain est possible pour le champ lointain
* Le champ lointain se forme pour les dipôles à une distance d'environ 4λ
* Lors du calcul avec l'approximation du champ lointain, la distance de sécurité s'applique à partir de chaque point de l'antenne
