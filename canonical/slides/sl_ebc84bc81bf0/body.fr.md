<left>
* Si un courant variable dans le temps circule dans un conducteur, par exemple une antenne, un champ électrique ainsi qu'un champ magnétique sont générés
* Celui-ci est appelé champ électromagnétique
* Les deux champs sont à un angle de $\qty{90}{\degree}$ l'un par rapport à l'autre
