## Signaux Morse
<left>
* Semblables aux signaux de fumée
* L’appareil radio produit une oscillation à l’aide d’un oscillateur
* L’appui sur la touche Morse envoie cette oscillation vers l’antenne
* Le récepteur rend l’émission audible
* Possibilité de distinguer les appuis courts, longs et les pauses
</left>
<right>
[photo:109:n_cwtast:Claviers Morse]
</right>
<note>
* Les signaux Morse sont « donnés »
* L’ensemble est appelé Continuous Wave (CW)
</note>

---

* Accord sur la signification de certaines séquences de durées variables
* Au milieu du XIXe siècle, adoption du code Morse encore utilisé aujourd’hui

<note>
Exemple :
* *long, court, long, court* : C
* *long, long, court, long* : Q
</note>

## Télégraphie
* Procédé de transmission utilisant un moyen auxiliaire
* La fumée ou l’oscillation électrique est modifiée pour transmettre un message
* Le moyen auxiliaire est le *porteur*
* En radio, en raison des hautes fréquences, on parle aussi de *porteuse haute fréquence* ou *porteuse HF*
* Le procédé permettant de modifier le porteur s’appelle la *modulation*

<note>
Télégraphie du grec ancien :
* τῆλε (têle) → loin
* γράφειν (graphein) → écrire ou dessiner

Modulation du latin :
* Modulatio → mesure ou rythme
</note>

## Autres types de modulation

L’oscillation électrique peut être modulée de différentes manières :
* Par l’intensité (amplitude)
* Par la durée (fréquence)
