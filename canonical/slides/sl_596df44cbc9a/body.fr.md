## Groupes Q

* composés de trois lettres et commençant par *Q*
* conçus à l’origine pour la télégraphie rapide
* utilisés aujourd’hui également en radiotéléphonie
* avec un point d’interrogation, généralement une question ; sans point d’interrogation, une affirmation ou une demande

--- style="font-size: smaller;"

### Groupes Q importants

| l: Groupe | X: Signification |
| QRM | Je suis brouillé par d’autres stations |
| QRN | Je suis gêné par des perturbations atmosphériques |
| QRO? | Dois-je augmenter la puissance d’émission ? |
| QRT | Arrêtez la transmission |
| QRV | Je suis prêt |

--- style="font-size: smaller;"

### Autres groupes Q importants

| l: Groupe | X: Signification |
| QRX? | Quand me rappellerez-vous ? |
| QRZ? | Qui me demande ? |
| QSB? | L’intensité de mes signaux varie-t-elle ? |
| QSL? | Pouvez-vous confirmer la réception ? |
| QSO? | Pouvez-vous communiquer avec une station déterminée ? |
| QTH | Ma position est ... |

<note>
Astuce mnémotechnique : QRM désigne une perturbation d’origine humaine, QRN une perturbation naturelle, et QSB correspond à une variation de l’intensité du signal.
</note>
