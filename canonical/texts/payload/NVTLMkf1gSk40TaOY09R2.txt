De nombreux appareils radio disposent d'un port appelé DATA, souvent marqué *DATA* ou *$\qty{9600}{\baud}$*, comme le montre la figure [ref:e_9600_port]. Ce port a été développé à l'origine pour les applications Packet-Radio, qui ont été largement remplacées par HAMNET aujourd'hui. Néanmoins, cette connexion peut également être utilisée pour d'autres procédés, comme le procédé de transmission vocale numérique M17. Dans ce cas, un modem correspondant - souvent appelé TNC - est connecté, comme le montre la figure [ref:m17_tnc].

Le port $\qty{9600}{\baud}$ offre une connexion directe au modulateur et au démodulateur de l'émetteur-récepteur afin de traiter les signaux avec une grande précision et de faibles distorsions. Pour des débits de données plus élevés, tels que ceux utilisés dans les signaux numériques, par exemple dans le Packet-Radio $\qty{9600}{\baud}$ (protocole AX.25), il est nécessaire de contourner l'ensemble du chemin audio avec sa bande passante limitée et ses filtrages (par exemple, le filtre du microphone et le préamplificateur). Le chemin audio d'un émetteur-récepteur est généralement adapté aux signaux vocaux et a une bande passante limitée, souvent comprise entre $\qty{300}{\hertz}$ et $\qty{3000}{\hertz}$. Cette bande passante n'est pas suffisante pour transmettre de manière fiable $\qty{9600}{\baud}$, car un taux aussi élevé nécessite une plus grande largeur de signal. Les signaux sont transmis via la connexion de données sans les filtres, le traitement DSP et le processus de désaccentuation présents dans le chemin audio. Cela réduit les distorsions et les latences, ce qui est crucial pour les transmissions numériques afin de minimiser le taux d'erreur. 

En résumé : le port $\qty{9600}{\baud}$ est spécialement conçu pour traiter les données numériques directement et sans les limitations du chemin audio, ce qui est nécessaire pour une transmission de données fiable et efficace à haute vitesse.

<indepth>
Pourquoi $\qty{9600}{\baud}$ exactement ?
  
$\qty{9600}{\baud}$ ($\qty{9,6}{\kilo\bit\per\second}$, si une modulation avec un bit par symbole est utilisée) est une vitesse courante pour la communication numérique dans le radioamateur, en particulier dans le Packet-Radio. Ce débit de données représente un compromis entre la vitesse atteignable et la faisabilité technique dans la gamme de fréquences VHF/UHF, où la plupart des émetteurs-récepteurs FM fonctionnent.
</indepth>
