Description détaillée : En haut se trouve un symbole d'antenne qui mène vers le bas via une ligne verticale. Dans cette ligne verticale se trouve au milieu une bobine (inductance) entre deux points de connexion noirs. Du point de connexion inférieur, une courte ligne mène vers le bas à un symbole de masse. Des points de connexion supérieur et inférieur partent vers la droite, chacun via des lignes horizontales vers un boîtier rectangulaire avec l'inscription « RX » (les deux lignes représentent les connexions). Entre le point de connexion supérieur et le point de connexion inférieur, une boucle conductrice rectangulaire s'étend à gauche ; dans le côté gauche de cette boucle, un condensateur réglable est représenté (deux plaques de condensateur avec une ligne diagonale oblique). À gauche du condensateur se trouve le texte « Accordé sur le signal parasite », une flèche pointe de ce texte vers le condensateur réglable.
