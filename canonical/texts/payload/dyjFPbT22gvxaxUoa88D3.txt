Circuit imprimé en conduite rectangulaire avec deux conducteurs horizontaux parallèles et deux points de connexion à gauche (désignés par « ZF ») ; condensateur entre les deux conducteurs horizontaux ; transformateur ; à son enroulement secondaire, un autre condensateur entre les conducteurs horizontaux ; diode dans le conducteur supérieur ; un autre condensateur entre les conducteurs horizontaux ; en parallèle, une résistance ; vers le haut, un autre condensateur vers le 3ème point de connexion à droite ; dans le conducteur supérieur, une résistance ; ensuite, un condensateur entre les conducteurs horizontaux ; deux points de connexion vers la droite, celui du conducteur horizontal supérieur étant marqué « X ».
