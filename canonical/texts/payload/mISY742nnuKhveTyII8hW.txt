### TDMA
<left>
* Time Division Multiple Access – Procédé de multiplexage temporel
* Les données numériques utiles sont séparées et envoyées successivement sur la même fréquence
* Au récepteur, le flux de données est recomposé
</left>
<right>

</right>

### CDMA
<left>
* Code Division Multiple Access – Procédé de multiplexage par code
* Les données numériques utiles sont codées (mélangées) avec un code numérique
* Au récepteur, le même code numérique est utilisé pour le décodage
</left>
<right>
[picture:846:e_vielfachzugriff_cdma:Procédé de multiplexage par code avec trois signaux]
</right>
<note>
* Plusieurs signaux peuvent être transmis sur la même fréquence 
</note>

### FDMA
<left>
* Frequency Division Multiple Access – Procédé de multiplexage par fréquence
* Le signal numérique est divisé sur plusieurs fréquences
* Cela permet d'utiliser plus de bande passante
</left>
<right>
[picture:845:e_vielfachzugriff_cdma:Procédé de multiplexage par fréquence avec trois signaux]
