Un ajustement de $\qty{50}{\ohm}$ à $\qty{2500}{\ohm}$ est donné.

Tout d'abord, nous déterminons le rapport d'impédance nécessaire (du point de vue de l'antenne) :

$ \frac{Z_P}{Z_S} = \frac{2500}{50} = 50$

Le transformateur doit donc réaliser un rapport d'impédance d'environ $1:50$.

Pour les transformateurs, le rapport d'impédance est le carré du rapport de spires :

$\left(\frac{N_2}{N_1}\right)^2 = 50$

Il en résulte pour le rapport de spires :

$\frac{N_2}{N_1} = \sqrt{50} \approx 7$

Le rapport de spires recherché est donc approximativement :

$1:7$
