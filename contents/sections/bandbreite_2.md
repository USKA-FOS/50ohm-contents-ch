Die Bandbreite eines Signals oder einer Aussendung wird in Hertz ($\unit{\hertz}$) bemessen. Hierbei misst man die Bandbreite eines Signals durch Messung der Differenz zwischen maximaler und minimaler Sendefrequenz der Aussendung.

<indepth>
Die Bandbreite gibt also an, wieviel Spektrum das Signal beansprucht. Üblicherweise messen wir die Bandbreite eines Signals zwischen den Frequenzpunkten, bei denen die spektrale Leistung auf $\frac{1}{2}$ (entsprechend $\qty{-3}{\dB}$) des Spitzenwerts abgefallen ist.

%Ergänzen mit Bandbreite Audrücken (RR AP1, §2. Siehe Merkblatt 2021, SEite 10)

Es gibt im Radio Reglement eine spezielle Nomenklatur zur Beschreibung der erforderlichen Bandbreite.

**RR AP 1 – Abschnitt I: Erforderliche Bandbreite**

*§ 2*

*1)* Die in Ziffer 1.152 definierte erforderliche Bandbreite muss durch drei Ziffern und einen Buchstaben ausgedrückt werden. Der Buchstabe nimmt die Stelle des Kommas ein und stellt die Einheit für die Bandbreite dar.

Das erste Schriftzeichen darf weder die Ziffer Null noch einer der Buchstaben K, M oder G sein.

*2)* Die erforderlichen Bandbreiten werden wie folgt ausgedrückt:

| Bandbreite | Einheit |
|            |         |
| Zwischen 0,001 und 999 Hz | Hz (Buchstabe H) |
| Zwischen 1,00 und 999 kHz | kHz (Buchstabe K) |
| Zwischen 1,00 und 999 MHz | MHz (Buchstabe M) |
| Zwischen 1,00 und 999 GHz | GHz (Buchstabe G) |

*Beispiele:*


| Bandbreite | Schreibweise |
|            |              |
| 0,002 Hz | H002 |
| 0,1 Hz | H100 |
| 25,3 Hz | 25H3 |
| 400 Hz | 400H |
| 2,4 kHz | 2K40 |
| 6 kHz | 6K00 |
| 12,5 kHz | 12K5 |
| 180,4 kHz | 180K |
| 180,5 kHz | 181K |
| 180,7 kHz | 181K |
| 1,25 MHz | 1M25 |
| 2 MHz | 2M00 |
| 10 MHz | 10M0 |
| 202 MHz | 202M |
| 5,65 GHz | 5G65 |

*Definition aus den "Radio Regulations":*
  
Die Ziffer 1.152 definiert die notwendige Bandbreite:
Für eine gegebene Emissionsklasse die Breite des Frequenzbandes, die gerade ausreicht, um die Übertragung von Informationen mit der erforderlichen Geschwindigkeit und Qualität unter festgelegten Bedingungen sicherzustellen.

Das vollständige, sehr umfangreiche Dokument **"Classification of emissions and necessary bandwidths"** befindet sich hier: [RR2016-Vol-II_App1_E.pdf](https://www.itu.int/en/ITU-R/terrestrial/workshops/WRS-16/Documents/RR2016-Vol-II_App1_E.pdf).
