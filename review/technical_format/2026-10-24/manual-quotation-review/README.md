# Revue manuelle des guillemets — intégration acceptée

35 objets et leurs 105 fichiers ont été examinés par l’utilisateur. Les 27 copies modifiées (15 FR, 12 IT, 21 objets) sont importées à l’identique après contrôle des empreintes. Aucun allemand ne change.

Les fichiers revus sans modification sont également acceptés. Une différence de compte ne doit pas imposer des guillemets inutiles dans la langue cible. Les diagnostics restent conservés dans le plan comme éléments de contrôle, sans remplacer les décisions humaines.

Le manifeste de départ est archivé dans `review-manifest.snapshot.json`, avec tous les textes d’origine. `import-plan.json` conserve les 105 décisions, les empreintes, les diagnostics et les textes humains des 27 modifications ; `changes.patch` en donne le diff. L’application est documentée séparément dans `application.json`. Les copies de travail humaines sont préservées.
